# Repuls.io Precise Crosshair  A lightweight, high-precision custom crosshair userscript for **Repuls.io**.  ## Features - **Precise**: 3px micro-dot. - **Visible**: Neon green with black border. - **Fair**: 100% safe UI tweak.  ## Install 1. Install Tampermonkey. 2. Paste `repuls-crosshair.user.js` in a new script. 3. Save &amp; play on Repuls.io!
